===========================
Package Label customization
===========================

::

    This is a specific customization for package label. It uses SSCC code
    from stock_picking_sscc module and Number of Packages from delivery_package_number
    module.

Configuration
=============
::

    Configure SSCC code creation

Usage
=====
::

    Select a stock picking and click on "Print Label" button. Remember to
    set Number of Packages for picking, because unless the printed label
    will be empty.

Known issues / Roadmap
======================
::

    The module should not create issues together with other modules.
