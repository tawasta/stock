======================================================================
Stock Picking: Hide Parent Location Hierachy On Lines on Picking Print
======================================================================

* Only show the location name, without its parents' names

Configuration
=============
* None needed

Usage
=====
* Just print an outgoing delivery document's picking operations print. 
  The source location's parent names are omitted.
