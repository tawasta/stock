============================================================
Stock Picking: Delivery Slip Template without Recipient Info
============================================================

* Adds a second delivery slip that hides all address info
  from the PDF header

Configuration
=============
* None needed

Usage
=====
* Find the new delivery slip in picking operations' print menu.
* You still have the option to print the regular delivery slip
  as well, it does not get replaced.
