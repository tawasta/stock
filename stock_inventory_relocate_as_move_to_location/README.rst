===================================================================================
Replace Relocate button in Stock Inventory list view with 'Move to location' action
===================================================================================

::

    Relocate button in Stock Inventory list view is replaced with 'Move to location' action

Configuration
=============
::

    None needed

Usage
=====
::

    Install the module and see how Relocate button has been hidden
    in inventory list view. 'Move to location' action is shown instead.

Known issues / Roadmap
======================
::

    Only a view change
