===============================
Stock Location Name Options
===============================
Adds option for location transfer reports and stickers to have location.name 
in place of location.complete_name. Also adds optional fields for short names to all 
lists that normally display locations.

Installation
============
* Install the module

Configuration
=============
* In the Settings -> Inventory -> Warehouse
	* Choose name what report naming style you want to use

Usage
=====
* Install
* Configure
* Use in stock location transfers and reports
