============================
Stock Picking Note Indicator
============================

This module adds a visual warning indicator to Stock Pickings when the
internal ``Note`` field contains text.

The warning is displayed directly on the picking form view before the notebook
tabs, ensuring that warehouse users notice important instructions before
processing or validating the transfer.

Features
========

* Adds a computed boolean field ``has_note_text`` to ``stock.picking``
* Detects whether the HTML note field contains actual text content
* Ignores empty HTML generated by the editor (for example ``<p><br></p>``)
* Displays a professional warning banner on the picking form
* Helps users notice operational instructions before validation

Configuration
=============
* None needed

Usage
=====

#. Open a Stock Picking.
#. Add content to the ``Note`` tab.
#. Save the picking.
#. A warning banner is displayed on the form view informing the user that
   the picking contains internal notes requiring attention.
