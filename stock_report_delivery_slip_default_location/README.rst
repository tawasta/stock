======================================
Show Default Location in Delivery Slip
======================================

::

    Show informative Default Location of a product in Delivery Slip

Configuration
=============
::

    stock and stock_move_product_default_location modules need to be installed

Usage
=====
::

    Set a default location for a product. Then select a picking and print its
    delivery slip PDF print.

Known issues / Roadmap
======================
::

    This module should not disturb other installed modules, but the added column
    in delivery slip will take up space.
