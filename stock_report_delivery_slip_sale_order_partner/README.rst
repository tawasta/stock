=============================================================
Stock Picking: Show Sale Order Partner on Delivery Slip Print
=============================================================

* If picking operation is related to a Sale Order, show
  the SO's partner on the Delivery Slip print

Configuration
=============
* None needed

Usage
=====
* Create and confirm a sale with different partner and delivery addresses
* Print the delivery document's delivery slip print. Also the original
  Sale Order partner is shown on the PDF
