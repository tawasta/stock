========================================
Stock Location is checked if it is Empty
========================================

::

    The module edits search and list views of stock locations.
    A user can then check which locations are empty. Each location
    has a value attached to its "Is Empty" field to show if it is
    empty or not.

Configuration
=============
::

    No configuration is necessary

Usage
=====
::

    Install the module from Apps

Known issues / Roadmap
======================
::

    Added field is purely informative and it does not disturb any Odoo processes.
