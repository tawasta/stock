===================================================================
Stock Picking and Delivery Slip Report: Force Left-Aligned Headings
===================================================================

* Adds separate toggles for reports to enforce th element alignment
* Intended for situations where the prints end up looking messy
  due to some of the columns being center-aligned and others
  left-aligned
* This module enforces alignment with CSS, so it should cover
  also the th elements that get added by other custom modules

Configuration
=============
* Go to Stock settings and toggle these new settings:

  * Left-align Picking Report Headings
  * Left-align Delivery Slip Headings

Usage
=====
* Just print one of the two stock reports
