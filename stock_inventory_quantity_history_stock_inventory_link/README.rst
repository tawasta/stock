==============================================================================
Stock Inventory Theoretical Quantity History / Stock Inventory Adjustment Link
==============================================================================

* Show the quantity fields provided by 'Stock Inventory Theoretical Quantity History'
  OCA module also in the stock.move.line list view provided by 
  'Stock Inventory Adjustment' module.

Configuration
=============
* None needed

Usage
=====
* Open an Inventory Adjustment Group with some inventories done
* Click Stock Moves Lines action button to see the qty fields
