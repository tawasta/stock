==============================================================
Stock Picking: Product Barcodes on Delivery Slip Print's Lines
==============================================================

* Show products' barcodes in numeric format on Delivery Slip

Configuration
=============
* None needed

Usage
=====

* Just print the delivery document's delivery slip print

Known issues / Roadmap
======================
* Consider adding a configurable option for showing the barcode 
  as numeric or as an actual readable barcode.
* Consider adding a configurable table heading text instead
  of just 'EAN'
