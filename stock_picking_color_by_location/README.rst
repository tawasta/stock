========================================
Stock Picking colored by their locations
========================================

Pickings are colored if their source or destination location has enabled coloring.
This is used to better see certain pickings from where or where to are transferred.

Configuration
=============
Select a location and choose a coloring option.

'Use Destination color in tree view' setting colors pickings that use
this location as its destination.

'Use Source location color in tree view' setting colors pickings that use
this location as its source.

Usage
=====
Install the module and change settings in some locations. Then see
how picking list view has colors on some pickings.

Known issues / Roadmap
======================
Coloring functionality does not disturb anything, since it is just
styling for pickings.
