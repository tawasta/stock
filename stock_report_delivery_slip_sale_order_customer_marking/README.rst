Stock Picking: Show Sale Order's 'Customer Marking' on Delivery Slip Print
==========================================================================

* If picking operation is related to a Sale Order, show 
  the SO's 'Customer Marking' on the Delivery Slip print

Configuration
=============
* None needed

Configuration
=============
* None needed

Usage
=====
* Just print the delivery document's picking delivery slip print
