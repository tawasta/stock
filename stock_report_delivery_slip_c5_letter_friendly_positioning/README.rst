===================================================
Stock Report Delivery Slip: C5-friendly Positioning
===================================================

* Repositions the recipient information on the delivery slip print to the
  left side, so that it aligns with the window of a C5 letter

Configuration
=============
* If the default alignment does not match the window of the used letters,
  adjust the "Delivery Slip: C5 Letter Address Offset" values in
  Inventory -> Configuration -> Settings -> Shipping.

Usage
=====
* Just install the module and print a delivery slip
