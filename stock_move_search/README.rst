===============================================
Stock Move Search: Additional Filters/Groupings
===============================================

* Additional Search/reporting options for Stock Move
  * Product Template
  * Product Category
  * Partner Country

Configuration
=============
* None needed

Usage
=====
* Go to Inventory -> Reporting -> Move Analysis to see the new filters and grouping options
