========================================================================
Prevent hard refreshing a page after Button validate has printed reports
========================================================================

Sometimes a user does not want the page to be reloaded completely after a picking
has been validated and their respective reports have been printed.

This module reloads a page only softly so that the data is refreshed
and recently validated pickings are shown as validated.

Configuration
=============
There is no need to do any configuration

Usage
=====
Installing this module makes it ready to use

Known issues / Roadmap
======================
There might some situations when a complete refresh of a web page is a wanted behaviour
