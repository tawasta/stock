=======================================
Stock Account: Inventory Valuation Menu
=======================================

* Adds the Inventory Valuation report of ``stock_account`` as a menu item
  under Accounting / Review. The core module has the report but no menu for it.

Configuration
=============
\-

Usage
=====
* Go to Accounting / Review / Inventory Valuation.
* The menu item is visible to the users who see the Review menu
  (Accounting read-only access).
