==============================================================
Stock: Set Delivery Slip and Picking PDF company as SO company
==============================================================

* Look what is the company of a sale order and use it on Delivery Slip
  and Picking List.
* Fall back to picking document's own company, if no related sale
  exists

Configuration
=============
* None needed

Usage
=====
* Generate a delivery order from a sale order, and print its Picking List
  and Delivery Slip
