=========================================
Stock Quant list view – Show product tags
=========================================

Show product tags in stock quant tree view

Configuration
=============
None needed

Usage
=====
Go to Apps to install the module

Known issues / Roadmap
======================
The module only adds an informative product tags -field to
stock quant list view. So it does not create any possible
issues in odoo.
