====================================
Delivery Slip – Hide Invoice address
====================================

::

    Hide Invoice address from Delivery Slip. A new stock report
    named "Delivery slip with delivery address only" is added to
    printable reports in pickings.

Configuration
=============
::

    stock module needs to be installed

Usage
=====
::

    Select a picking and print its PDF which is
    named "Delivery slip with delivery address only"

======================
