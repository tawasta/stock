========================================================================
Stock Picking: Show Sale Order 'Customer Contact' on Delivery Slip Print
========================================================================

* If picking operation is related to a Sale Order, show 
  the SO's Customer Contact person on the Delivery Slip print

Configuration
=============
* None needed

Usage
=====
* Create and confirm a sale, and print the delivery document's 
  delivery slip print.
