======================================
Stock Picking: Mark Picking as Printed
======================================

* Mark stock pickings as printed and log date after printing picking list

Configuration
=============
* None needed

Usage
=====
* Print the Picking Operations printout, and a new "Picking Printed" field
  will appear on the picking form.
