==========================
Stock Picking: Done filter
==========================
This module adds a **"Done"** filter to the stock picking search view
in Odoo's Inventory module.


Configuration
=============
* None needed

Usage
=====
1. Go to **Inventory → Internal Transfers**
2. In the search view, select the new **Done** filter to show only completed pickings.
