===========================================================
Stock Picking: Hide HS Codes on Delivery Slip Print's Lines
===========================================================

* Don't show products' HS Codes on the delivery slip PDF

Configuration
=============
* None needed

Usage
=====
* Just print the delivery document's delivery slip print

Known issues / Roadmap
======================
* Note that HS Codes come from `stock_delivery`. If you do not have
  that module installed in the first place, this module is not 
  needed for your setup.
